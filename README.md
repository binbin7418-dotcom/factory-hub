# 产品工厂中枢（Factory Hub）

本仓库是 Vision 全部数字产品的**总控与交接中枢**：产品总索引、立项验证流水线、交接手册都在这里。任何人（或任何智能体）在任何平台接手，先读完本仓的 README、PIPELINE、HANDOVER 三份文档，就能继续开发、测试、上架和维护全部产品，不依赖某个会话的记忆。

## 战略目标（2026-10-25 定版）

三条产品线，各做到 **100 个产品**：

| 产品线 | 形态 | 收款 |
|---|---|---|
| Gumroad | 本地运行的 Windows 工具（检查→修复→复检类），$29 一次性 | PayPal（经 Gumroad，中国区最低打款 $100 周结） |
| RapidAPI | 托管 API（工具类/数据类），免费层 + PRO 订阅 | PayPal 月结，平台抽 25% |
| n8n | 自动化工作流模板包 + Fiverr 代建服务 | Fiverr → Payoneer |

**质量铁律（压倒数量）**：每个产品必须过五关验证（见 PIPELINE.md）——有真实付费证据、拆过竞品为什么好卖、种子缺陷验收通过、功能完整并附顾客使用说明。验证不过不上架，宁可慢，不堆垃圾凑数。算账只认真实到账。

## 文档导航

- `PIPELINE.md` —— 五关验证流水线：立项到下架的完整标准与检查清单
- `HANDOVER.md` —— 交接手册：构建配方、测试方法、上架流程、收款与账号、运维节奏、避坑清单
- `PRODUCTS.md` —— 全部产品注册表：每个产品的状态、链接、仓库、验收数据、维护说明
